# Juego RE-ORG BCM

Juego-test interactivo para capacitar en el almacenaje de la colección de **Bienes Culturales Muebles (BCM)** del **INAH · Arqueología Subacuática · Campeche**, aplicando el método **RE-ORG** (ICCROM · UNESCO · CCI).

Es un **solo archivo HTML**, funciona **sin conexión** (doble clic) y también puede publicarse en la web.

## Contenido
- **`index.html`** / **`Juego_RE-ORG_BCM.html`** — el juego completo (mismo archivo).
- **`Actividad_Propuesta_RE-ORG.pdf`** — actividad de propuesta que se realiza **a mano** sobre el plano real de Campeche (3 páginas: hoja de trabajo + planta baja + niveles 1 y 2).

## Cómo usarlo
1. Descarga el repositorio (o solo `index.html`).
2. Abre **`index.html`** con doble clic en Chrome o Edge.
3. Cada participante escribe su **nombre** y juega las 7 etapas: Bodega → Mobiliario → Contenedores → Distribución (plano con cuartos, puertas/ventanas a cerrar, deshumidificadores con rango y dataloggers) → Colección (desalinización por material, regla de pila galvánica) → Examen → Reporte.
4. El instructor entra a **📊 Estadísticas del grupo** (PIN **5050**) para ver qué se falla más.
   - Los datos se guardan por navegador (localStorage).

## Ver en línea (GitHub Pages)
